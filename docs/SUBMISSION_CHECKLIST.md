# Hackathon submission checklist

- [ ] `npm install` succeeds.
- [ ] `npm run dev` starts and login works with `demo` / `gapfinder2026`.
- [ ] Load the sample notes.
- [ ] Quiz can be completed and gap report displays.
- [ ] Revision plan changes when available study time changes.
- [ ] Topic assistant shows source references.
- [ ] Add `GEMINI_API_KEY` and verify live generation (if available).
- [ ] Push code to GitHub; confirm `.env.local` is not committed.
- [ ] Deploy to Vercel and test the deployed app.
- [ ] Put the hosted URL, GitHub URL, demo credentials, setup steps, and limitations in the submission form.
- [ ] State honestly that this prototype uses lexical retrieval; do not claim pgvector/semantic embeddings unless implemented.
